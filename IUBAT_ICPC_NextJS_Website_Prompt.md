# Prompt: Build an ICPC Asia Dhaka Regional (IUBAT Host) Website using Next.js

You are a senior frontend engineer and UI/UX designer.

Design and develop a modern, premium-quality website for the **ICPC Asia Dhaka Regional Contest hosted by IUBAT (International University of Business Agriculture and Technology)**.

The website should feel comparable to international conference websites such as Google I/O, Microsoft Build, ICPC World Finals, ACM conferences, or Apple event websites.

## Technology Stack

- Next.js (Latest App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons
- shadcn/ui
- React Hook Form
- Zod
- SwiperJS
- React CountUp
- React Intersection Observer
- next/image
- next/font
- ESLint
- Prettier

Use a reusable, component-based architecture.

## Design Style

- Premium, clean, modern, academic
- Responsive (Desktop, Tablet, Mobile)
- Light & Dark Mode
- Glassmorphism where appropriate
- Rounded cards
- Smooth animations
- Large typography
- White space
- IUBAT-inspired blue, white, gray and gold palette
